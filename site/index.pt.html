Forja

Um backend de código aberto em um executável.

O Forja guarda os dados num arquivo SQLite, autentica usuários e serve o painel no mesmo processo. A API HTTP segue a do PocketBase, e o cliente Python do PocketBase já funciona nas rotas que existem.

0.0.3, em desenvolvimento

O que roda na 0.0.3.

Um arquivo SQLite

O banco é um data.db em modo WAL. Não há outro servidor de banco para instalar.

E-mail e senha

Login de superusuário e contas com verificação, redefinição de senha e troca de e-mail. A mensagem sai no console. SMTP fica para depois.

Registros e regras

Listar, criar, ler, atualizar e apagar, com filtro, ordenação, paginação e regras de acesso, no formato de pedido do PocketBase.

Painel em /_/

Entrar, e então listar, criar, editar e apagar registros. O editor de coleções não está nesta versão.

Para subir

Basta o Rust estável. O servidor escuta em 127.0.0.1:8090 e grava ./forja_data.

git clone https://github.com/iramarfalcao/Forjabase.git
cd forjabase
cargo run -p forja -- superuser upsert admin@example.com 'a-strong-password'
cargo run -p forja -- serve
curl http://127.0.0.1:8090/api/health

Clone e rode.

Não há binário publicado nem imagem do servidor. Clone o repositório, crie um superusuário e suba o servidor na porta 8090.
